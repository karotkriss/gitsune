Ahem.ttf is a W3C-maintained test font: every glyph renders as a fixed-size
box, which is why it is used here to make golden-test pixels independent of
whatever fonts happen to be installed on the machine running the tests.

Source: https://www.w3.org/Style/CSS/Test/Fonts/Ahem/COPYING
(vendored via the Ahem.ttf shipped inside the Flutter SDK's own tooling,
packages/flutter_tools/static/Ahem.ttf, which carries the same font unchanged)
