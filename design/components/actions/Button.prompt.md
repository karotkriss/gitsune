The action button. Confirm (solid brand orange) for the primary action on a screen — including Merge, which is orange, never green; danger (solid red) strictly for destructive actions.

```jsx
<Button variant="confirm" size="lg" block>Continue</Button>
<Button icon="retry">Retry</Button>
<Button variant="ghost" iconOnly icon="ellipsis_h" label="More actions" />
```

Hover darkens one ramp step, press two (Pajamas interactive-state rule).
