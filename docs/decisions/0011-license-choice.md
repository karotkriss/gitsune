# 11. License choice: MIT

- Status: accepted
- Date: 2026-08-25
- Amends: `docs/decisions/0006-strategy-and-positioning.md` (the exact license choice only)

## Context

`docs/decisions/` and the README both left the open-source license as an open, deliberate decision ("License: TBD") rather than an oversight, pending a maintainer ruling.
An OSS license is a prerequisite for F-Droid submission, whose review process requires a recognized open-source license before it will accept an app.

## Decision

Gitsune is licensed under the MIT License, chosen by the maintainer on 2026-08-25.
The license text lives in `LICENSE` at the repository root, copyright holder Christopher McKay (karotkriss).

## Consequences

The codebase permits permissive reuse: anyone may use, copy, modify, merge, publish, distribute, sublicense, and sell copies of the software, with attribution preserved via the copyright notice.
The F-Droid submission, previously blocked on having no license, is unblocked.
